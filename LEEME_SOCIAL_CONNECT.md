# JIMPORT Social Connect

Sin IA de pago. Publicación de flyers en Facebook, Instagram y Telegram con un clic tras seleccionar redes y revisar el contenido. Otras redes conservan publicación manual. No se promete seguridad absoluta ni aprobación de las plataformas.

1. Subir archivos a GitHub. Ejecutar marketing-ai.sql completo en Supabase SQL Editor (incluye tabla nueva para credenciales cifradas).
2. Crear una aplicación comercial en Meta Developers y habilitar Facebook Login compatible con permisos de páginas e Instagram profesional. Registrar exactamente https://TU-DOMINIO/api/marketing-ai como redirect URI. Vincular Instagram profesional a la página Facebook. Solicitar permisos cuando proceda: pages_show_list, pages_read_engagement, pages_manage_posts, instagram_basic, instagram_content_publish. En modo desarrollo solo cuentas autorizadas en la app. La página se fija por ID para evitar publicar en una página equivocada.
3. Configurar en Vercel (solo servidor, Production): SOCIAL_ORIGIN=https://TU-DOMINIO (sin barra final), META_APP_ID, META_APP_SECRET, META_GRAPH_VERSION (versión vigente habilitada en Meta), FB_PAGE_ID, SUPABASE_SERVICE_ROLE_KEY (clave de servicio secreta del proyecto), SOCIAL_ENCRYPTION_KEY (64 caracteres hex aleatorios: ejecutar `openssl rand -hex 32` localmente). Nunca compartir ni subir claves a GitHub. No usar variables públicas. Elimina tokens antiguos FB_PAGE_TOKEN e IG_ACCESS_TOKEN si migras a OAuth para evitar uso de configuración antigua. Redeploy.
4. Administrador > Marketing Studio > Conectar Facebook e Instagram. Autoriza en Meta, vuelve al administrador, pulsa Comprobar configuración. Selecciona las redes disponibles. Verifica con una publicación de prueba. La disponibilidad indica credenciales presentes, no prueba permisos efectivos. Si no hay Instagram vinculado solo se habilita Facebook.
5. Telegram: crea bot mediante BotFather, añádelo como administrador del canal con permiso de publicar; configura TELEGRAM_BOT_TOKEN y TELEGRAM_CHAT_ID en Vercel y redeploy. Nunca pegues el token en la web. No se utiliza OAuth de usuario para Telegram.
6. Para desconectar Meta usa el botón del administrador y revoca además la autorización en las integraciones comerciales de Facebook. Mantén la clave de cifrado estable; si se pierde, elimina la conexión y autoriza de nuevo. Los tokens pueden vencer o ser revocados. No reintentar publicaciones inciertas sin revisar la red.

Seguridad: OAuth con estado aleatorio y cookie cifrada HttpOnly/Secure/SameSite=Lax, caducidad de 10 minutos, destino fijo y página preseleccionada por ID, comprobación de administrador en operaciones POST, AES-256-GCM para el token persistente, tabla sin acceso para anon/authenticated. El bucket de flyers es público por necesidad de Instagram: únicamente imágenes destinadas a publicación. No se ha efectuado auditoría de seguridad ni prueba real de las APIs. Las conexiones TikTok, YouTube, WhatsApp y Marketplace siguen manuales; TikTok requiere consentimiento, revisión y requisitos específicos. No se eluden restricciones.
