JIMPORT — ALERTAS PRIVADAS Y REGISTRO DE VENTAS

1. Haz copia de seguridad de tu proyecto y de Supabase.
2. Sube los archivos de este ZIP a GitHub, reemplazando los anteriores.
3. En Supabase > SQL Editor ejecuta REGISTRO_VENTAS_Y_ALERTAS_SUPABASE.sql.
   Antes deben existir el inventario privado, la función jimport_is_admin y
   create_verified_purchase, creados por los scripts anteriores del proyecto.
4. Inicia sesión en admin.html y revisa los productos con borde rojo.
5. Pulsa «Ver solo stock bajo» para filtrar los que necesitan reposición.
6. En «Compras verificadas», selecciona producto, cantidad y referencia única.
   Confirma la venta para descontar unidades. Si dejas marcada la casilla,
   se genera además un código de opinión para enviar por WhatsApp.
   Si la desmarcas, se registra una venta manual sin código.
7. Verifica que la cantidad se redujo y la alerta se actualizó.

IMPORTANTE:
- Un clic de WhatsApp en la tienda NO es una venta: no descuenta inventario.
- Generar un código desde el formulario actualizado SÍ confirma la venta y descuenta stock.
- Las ventas antiguas no se descuentan retroactivamente.
- Cada combinación producto + referencia se puede registrar una sola vez.
- El historial queda guardado en public.jimport_sales y solo se accede mediante
  el SQL Editor con permisos del propietario; no está publicado a clientes.
- Los costos y cantidades están en la tabla privada con RLS; las marcas rojas
  aparecen solo en admin.html, nunca en index.html.
- Si falla la creación del código, la transacción completa se revierte.
- Para corregir ventas erróneas, ajusta el inventario desde el administrador
  y documenta la corrección en tus registros internos.
